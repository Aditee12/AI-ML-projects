# 🤖 AI & ML Projects

Welcome to the **AI-ML Projects** repository! This repo contains a collection of machine learning and artificial intelligence mini-projects built using Python. Each script focuses on solving a specific real-world problem using ML techniques.

---

## 📁 Project List

1. **AI-Based Customer Segmentation using K-Means**  
   Uses clustering to group customers based on their spending behavior and features.

2. **chatbot.py**  
   A simple rule-based chatbot created using Python.

3. **fakenew.py**  
   A machine learning model to detect fake news based on text classification.

4. **frauddetection.py**  
   Detects fraudulent transactions using supervised learning techniques.

5. **houseprice.py**  
   Predicts house prices based on features like area, location, number of rooms, etc.

6. **movieprediction.py**  
   Predicts movie ratings or genres using ML models (could be regression or classification).

7. **product.py**  
   Likely predicts product sales or categorizes products (based on your script’s logic).
